# سقف | Saqf
A modern Persian RTL marketplace for products, services, creators and local businesses.

## Stack
- Next.js + TypeScript + Tailwind CSS
- Node.js + Express + TypeScript API
- Ready for PostgreSQL/Prisma, object storage and Socket.IO
- Render-ready Blueprint

## Run
npm install
npm run dev

Web: http://localhost:3000
API: http://localhost:4000/health
